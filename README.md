# André Silva — web CV

Static, dependency-free terminal portfolio based on Andre_Silva_CV.pdf, supplied on 12 October 2026. Original code and procedural canvas graphics; visual direction follows hancore.dev. The AI Agent Factory sibling project is untouched.

Run `npm start`, then visit http://127.0.0.1:8791. Hosting serves `dist/` directly. Edit the section content in `dist/app.js`; styles and responsive layouts are in `dist/style.css`.

Features: code introduction, eight-section rotating navigation, keyboard shortcuts, terminal commands, four saved color themes, pointer-responsive ASCII eye, reduced-motion support, responsive mobile navigation, copy-email, mail/phone links, original CV download, and hash deep links. No analytics, fake visitor counts, external API calls, or required third-party runtime assets.

The PDF has flattened image pages and no embedded hyperlink targets. Its GitHub label has no recoverable URL, so the site does not guess a GitHub account. Ongoing education/courses remain marked in progress. CV phone and email appear on the contact page and inside the original downloadable PDF.
